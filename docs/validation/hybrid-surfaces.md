# Гибридные наблюдаемые поверхности — эксперимент

Ветка `feat/hybrid-observed-surfaces`, не принята в релиз. Численные пороги,
замороженные A/B/C и разметка не менялись. SHA и результаты сохранены в
`benchmarks/hybrid-surfaces/experiments.json`; закрытые координаты C исключены.

Первый вариант: A геометрия проходит, размеры 9/10 обеих сеток; C экспорт
прервался из-за нехватки локального диска, результатов качества нет.
После прямой подгонки вертикальных плоскостей в XY: A геометрия и размеры
10/10 проходят; C геометрия проходит, размеры ещё не все проходят. Новая
физика этих двух вариантов не запускалась.

Последний коммит a1c8f6b сохраняет наблюдаемые точки на уже найденной плоскости,
даже если их локальные нормали ненадёжны. Пять целевых тестов проходят;
полный прогон этого коммита пока не выполнен.

После сообщения пользователя о переполнении диска локальные тяжёлые запуски
остановлены. Дальнейшие реконструкции/калибровка выполняются на Spark, артефакты
C остаются только в закрытом каталоге жюри. Локально сохраняются исходники,
отчёты, канонический публичный архив и нужные превью. Исторические сборочные
архивы переносятся на Spark с проверкой SHA256 до удаления локальной копии;
временные побайтовые дубликаты пакета и wheelhouse удаляются после проверки.
