# Пакет данных v2

Участнический архив: [scan2sim_data_v2.tar.gz](http://10.10.0.2:18091/scan2sim_data_v2.tar.gz). Доступ без аккаунта организатора, только из LAN/VPN сервера 10.10.0.2. Публичный Internet URL не заявлен.

SHA256: `f37365cec7da525e07060966b558a4fcbd86249c19f903b6460e83e13ff0deb0`, размер 117968471 байт. Две независимые сборки дают одинаковые байты. Новая HTTP-сессия скачала архив, безопасно распаковала и проверила SHA256 всех 54 файлов; сведения — `public-package-v2.json`.

Включены A750000, trajectory_A, manifest m/Z, 10 размеров, проёмы, маршруты, описание общей области, test_config v2, фиксированный 10M, starter, правила и README. B, C, внутренние отчёты, GT PLY/USD и NVIDIA-ассеты исключены явным allowlist. Для самопроверки GT есть source manifest и fetch_gt; источник/условия указаны в скрипте. Three.js MIT license сохранена рядом с библиотекой интерфейса.

Частный архив жюри хранится отдельно на Spark: `/home/unknown641/lidar2sim-jury-private/scan2sim_jury_v2.tar.gz`. Он содержит полные A/B, разметку и GT A, финальную C с рецептом/GT/проверками, профиль и решение. Все файлы проверены по SHA256SUMS; каталог 700, архив 600. Его нельзя переносить в публичный HTTP-каталог. Реестр закрытого состава лежит рядом с архивом, не публикуется здесь.

Публичный сервер — `scan2sim-public-data-v2`, read-only bind только каталога публичного пакета, UID65534, без capabilities, bind `10.10.0.2:18091`. Никаких ключей и приватных каталогов в mount нет. Наличие ссылки не утверждает готовность финальной независимой репетиции H30 или прохождение реконструкции на C.

Повторная сборка из checkout:

```sh
uv run --locked --python python3.11 python tools/package_release.py \
  --scans data/scene_ab_v2 --dense data/scene_10m \
  --annotations out/annotations-v2-independent \
  --out out/release-rebuild/scan2sim_data_v2.tar.gz
```

Выходной файл должен отсутствовать; инструмент не перезаписывает выпущенный пакет. При изменении кода, правил или данных новый архив получает новый хеш и отдельный каталог до проверки и публикации.

Дополнительно проверены команды README в новой распаковке и новом venv: установка зависимостей 414.113 с, baseline 17.151 с, пример USD 1.157 с, fetch_gt 106.697 с. GT восстановлен из 543 слоёв NVIDIA; число треугольников и контрольные хеши совпали. Подробности: `participant-rehearsal-v2.json`. Использовался существующий пользователь и uv cache; это не независимая репетиция с отдельным аккаунтом.
