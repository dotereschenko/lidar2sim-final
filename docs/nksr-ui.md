# NKSR через UI

Исследовательский режим использует pretrained `kitchen-sink`, без дообучения
на загруженной комнате. Веса и версия исходников закреплены в
`lidar2sim/neural.py`; первый runtime описан в [nksr-runtime.md](nksr-runtime.md).

## Использование

Работающий экземпляр: **http://127.0.0.1:8767** через туннель на Spark.
Если вкладка была открыта до развёртывания модели, обновить страницу.

1. Открыть локальный UI через SSH-туннель на сервер Spark.
2. Загрузить PLY. Указать фактические единицы и вертикальную ось; при наличии
   добавить CSV траектории `t,x,y,z`. Эти параметры нельзя угадать надёжно по PLY.
3. Выбрать «Нейросетевая реконструкция — NKSR». Недоступный на сервере режим
   отключён; причина показана под выбором метода.
4. Нажать «Построить сцену». Отображаются подготовка нормалей, NKSR,
   подготовка коллизий и экспорт. Можно отменить задание и отправить новое.
5. Переключать «Облако / Visual / Collision», скачать `scene.usd` и `report.json`.

Цвета скана переносятся на вершины visual и в displayColor USD. Collision —
статическая треугольная сетка. Выход — метры, Z вверх; исходник сохраняется.
Без независимой геометрической оценки и Isaac-тестов результат не проверен:
успешный экспорт не означает приёмку сцены. UI сам Isaac пока не запускает.

Входные нормали сохраняются и поворачиваются вместе с координатами. При их
отсутствии они оцениваются; без траектории используется согласование локальных
касательных плоскостей и общая ориентация внутрь. Это предположение для помещения,
а не доказанное направление каждой стенки. Метод и ограничение записаны в отчёт.

## Развёртывание на Spark

Сначала собрать runtime по [инструкции H42](nksr-runtime.md), затем из корня
данной ветки на сервере:

```sh
docker build --network=host -f deployment/Dockerfile.nksr-ui -t lidar2sim-nksr:ui .
```

Запускать отдельный экземпляр с собственным каталогом заданий. Не монтировать
Docker socket и не менять работающие Isaac-сессии. Один worker, 30 минут на
задание; отмена завершает только группу процессов выбранного задания.
Для доступа с ноутбука: `ssh -N -L 8767:127.0.0.1:8767 spark`.

Контейнеру нужны `--runtime=nvidia -e NVIDIA_VISIBLE_DEVICES=all`, доступ только
к своему каталогу заданий и read-only mount к `weights/` в `/weights`. Использовать
непривилегированного пользователя, ограничение CPU/RAM, loopback HTTP и image ID
в `LIDAR2SIM_IMAGE_ID` для provenance. Проверенный адрес/образ записать после запуска.

## Границы первой реализации

- Веса берутся только из проверенного cache; отсутствующие веса не скачиваются автоматически.
- Профиль использует `detail_level=0`, `mise_iter=1`, voxel 3 см; chunking пока
  отключён. OOM/ошибка модели возвращаются явно, скрытой подмены Poisson нет.
- Poisson сохраняет свой preprocessing и параметры; новый путь нормалей
  включается только для NKSR.
- Это не завершение H47/H41: независимая квалификация и физика — отдельный этап.
