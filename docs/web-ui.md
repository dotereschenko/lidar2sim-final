# Локальный интерфейс реконструкции

Из корня checkout с установленными зависимостями:

```bash
.venv/bin/python -m lidar2sim.web.server
```

Открыть http://127.0.0.1:8765. Другой порт: `--port 8766`.

1. Выбрать PLY или перетащить его в область загрузки (до 512 MiB, до 20 млн точек на сервере).
2. Указать единицы и вертикальную ось. Облако и необязательная траектория CSV `t,x,y,z` должны иметь одинаковые единицы и оси. Выход всегда в метрах, Z вверх.
3. Выбрать baseline, улучшенный Poisson либо «Высокая детализация». Улучшенные режимы фильтруют неподтверждённые поверхности, восстанавливают пол и строят отдельный collision. Высокая детализация использует глубину Poisson 10 и до 200000 треугольников collision: она сохраняет проёмы на секторном A/B v2, но требует больше времени и памяти. Режим по умолчанию остался прежним; высокая детализация не гарантирует улучшения на любом облаке.
4. Нажать «Построить сцену». Сервер обрабатывает одно задание за раз; до 8 активных заданий, лимит 30 минут на задание. Статусы отражают очередь/обработку/результат, проценты не выдумываются.
5. Переключать облако / Visual / Collision, вращать мышью, приближать колёсиком, включать каркас и сбрасывать вид. Облако предпросмотра ограничено 100000 точек; реконструкция получает полное облако.
6. Скачать `scene.usd`, `visual.ply`, `collision.ply`, `report.json`, лог. История доступна после перезагрузки страницы.

Данные лежат в `out/web-jobs/<id>/`: оригинал, настройки нормализации, копия конфига, нормализованные входы, результат и лог. `web_upload` в отчёте связывает исходные файлы с нормализацией по SHA256. На перезапуске сервера незавершённые задания помечаются ошибкой; повтор создаётся загрузкой заново. Задания автоматически не удаляются: следите за свободным местом.

Это локальный однопользовательский сервер, привязанный только к loopback. Не предназначен для публикации через reverse proxy: нет пользователей, квот диска и изоляции недоверенных вычислений. Один сервер на каталог заданий. Three.js 0.180.0 включён локально с MIT-лицензией, CDN при работе не требуется.

Успешная реконструкция не является приёмкой. GT/B, размеры и Isaac из UI пока не запускаются; интерфейс честно показывает отсутствие проверки качества. Скачанный USD можно передать существующему операторскому процессу Spark. Приложение запускается из checkout: конфиги берутся из `configs/`.
