# Демо Lidar2Sim: PLY → сцена → физический прогон

Версия продукта: `a37d2c3`, включена в main 13 ноября 2026.
Сценарий записи интерфейса; наличие этой инструкции не означает, что видео снято.

## Проверенные данные

- UI: http://127.0.0.1:8768 через SSH-туннель к vkteacher.
- Реконструкция: `623f57d7c6ee406b91d76de9f15cc6cb`, A750000, NKSR.
- 750000 входных точек; 89618 треугольников visual, 59999 collision.
- Полный конвейер 25.4 с; инференс NKSR 1.86 с на A100.
- Физический прогон: `893a56a2dfec45e3ae04a001fb1f703c`, та же реконструкция.
- Точки пола: `-15.65 9.45 0.03` и `-15.65 10.45 0.03`.
- Цель достигнута за 8.1 с симуляционного времени; остаток до цели 0.14688 м.
- Это короткий проверенный участок, не приёмка всего помещения.

## Сценарий на 60–90 секунд

1. **Вход.** Показать загрузку PLY, единицы, ось вверх и метод NKSR.
   Если используется история, сказать «Открываем уже обработанный скан»;
   не изображать повторную загрузку или реконструкцию.
2. **Реконструкция.** Выбрать в истории `623f57d7`. Переключить Облако → Visual
   → Collision, повернуть сцену. Показать количество точек и время обработки.
3. **Маршрут.** Выбрать свои точки на этой сцене. Вставить две строки выше,
   проверить ID сцены. Предпросмотр рисует только маршрут.
4. **Физика.** Запустить Newton GPU и дождаться реального результата. Паузы
   можно вырезать, подписав ускорение. Для повторной записи можно открыть
   существующий прогон из истории и явно назвать его воспроизведением.
5. **Результат.** Показать «Цель достигнута», открыть сцену прогона и воспроизвести.
   Камеру приблизить к корпусу. Это измеренные состояния Newton, не RTX-рендер.
6. **Выход.** Показать ссылки visual.ply, collision.ply, scene.usd, report.json,
   а также recording.json и конфигурацию прогона.

Титр: «Исследовательский прототип. Предобученный NKSR + Newton CUDA.
Модель корпуса на сферических опорах; качество каждого скана проверяется отдельно».

## Честное представление возможностей

Не подменять выбранный скан примером A без явного перехода. Не использовать
архивное видео Isaac на Spark как запись текущего прогона. Не называть
упрощённый корпус полноценным колёсным роботом с навигацией. Не обещать
гарантированную реконструкцию любого PLY или прохождение всех маршрутов.

Сохранять исходную запись и итоговый MP4 в `out/product-demo/` (не в Git).
Вместе с видео сохранить ID реконструкции/прогона и фактическую версию кода.
