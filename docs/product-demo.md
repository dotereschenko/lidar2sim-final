# Демо Lidar2Sim: PLY → сцена → физический прогон

Версия продукта: `a37d2c3`, включена в main 13 ноября 2026.
Сценарий записи интерфейса; наличие этой инструкции не означает, что видео снято.

## Проверенные данные

- UI: http://127.0.0.1:8768 через SSH-туннель к vkteacher.
- Реконструкция: `623f57d7c6ee406b91d76de9f15cc6cb`, A750000, NKSR.
- 750000 входных точек; 89618 треугольников visual, 59999 collision.
- Полный конвейер 25.4 с; инференс NKSR 1.86 с на A100.
- Физический прогон: `893a56a2dfec45e3ae04a001fb1f703c`, та же реконструкция.
- Точки пола: `-15.65 9.45 0.03` и `-15.65 10.45 0.03`.
- Цель достигнута за 8.1 с симуляционного времени; остаток до цели 0.14688 м.
- Это короткий проверенный участок, не приёмка всего помещения.

## Сценарий на 60–90 секунд

1. **Вход.** Показать загрузку PLY, единицы, ось вверх и метод NKSR.
   Если используется история, сказать «Открываем уже обработанный скан»;
   не изображать повторную загрузку или реконструкцию.
2. **Реконструкция.** Выбрать в истории `623f57d7`. Переключить Облако → Visual
   → Collision, повернуть сцену. Показать количество точек и время обработки.
3. **Маршрут.** Выбрать свои точки на этой сцене. Вставить две строки выше,
   проверить ID сцены. Предпросмотр рисует только маршрут.
4. **Физика.** Запустить Newton GPU и дождаться реального результата. Паузы
   можно вырезать, подписав ускорение. Для повторной записи можно открыть
   существующий прогон из истории и явно назвать его воспроизведением.
5. **Результат.** Показать «Цель достигнута», открыть сцену прогона и воспроизвести.
   Камеру приблизить к корпусу. Это измеренные состояния Newton, не RTX-рендер.
6. **Выход.** Показать ссылки visual.ply, collision.ply, scene.usd, report.json,
   а также recording.json и конфигурацию прогона.

Титр: «Исследовательский прототип. Предобученный NKSR + Newton CUDA.
Модель корпуса на сферических опорах; качество каждого скана проверяется отдельно».

## Честное представление возможностей

Не подменять выбранный скан примером A без явного перехода. Не использовать
архивное видео Isaac на Spark как запись текущего прогона. Не называть
упрощённый корпус полноценным колёсным роботом с навигацией. Не обещать
гарантированную реконструкцию любого PLY или прохождение всех маршрутов.

Сохранять исходную запись и итоговый MP4 в `out/product-demo/` (не в Git).
Вместе с видео сохранить ID реконструкции/прогона и фактическую версию кода.

## Проморолик из реальных результатов (13 ноября)

Подготовлен отдельный монтаж на 45 секунд, 1920×1080, 20 fps. Это офлайн-визуализация
реальных PLY и состояний Newton, **не запись UI**. Данный факт подписан в ролике.
Вид сверху использует срез только для отображения; collision mesh физического
прогона не изменён. Для облака используется прореженный серверный preview,
для движения — позиции и quaternion из сохранённого прогона `893a56a2`.
Синтезированная музыкальная дорожка создана специально для ролика, без сэмплов.

Артефакты в `out/product-demo/`:

- `lidar2sim-promo-music.mp4` — итог с музыкой;
- `lidar2sim-promo.mp4` — версия без музыки;
- `provenance.json` — источник данных и SHA256;
- `reconstruction.json`, `simulation.json`, исходные PLY и USD — доказательства.

Рендер: `tools/render_product_promo.py`; музыка: `tools/promo_soundtrack.py`.
Скрипт проверяет принадлежность симуляции реконструкции, SHA256 USD и соответствие
метрик фиксированным титрам. Для другого примера нужно обновить сценарий и проверки.
Зависимости монтажа (Pillow, NumPy, FFmpeg) не добавлены в зависимости продукта.
Arial берётся из macOS; для другого ОС нужен путь к шрифту с кириллицей.

```sh
uv run --no-project --python .venv/bin/python --with pillow --with numpy \
  python tools/render_product_promo.py out/product-demo
.venv/bin/python tools/promo_soundtrack.py out/product-demo/original-music.wav
ffmpeg -y -i out/product-demo/lidar2sim-promo.mp4 \
  -i out/product-demo/original-music.wav -c:v copy -c:a aac -b:a 160k \
  -shortest -movflags +faststart out/product-demo/lidar2sim-promo-music.mp4
```

`geometry.npz` содержит массивы `v/f` из visual.ply, `cv/cf` из collision.ply,
`p` из input.ply (серверный preview), прочитанные Open3D. Внешний рендер не является
новым физическим тестом и не доказывает пригодность произвольного PLY.

### Монтаж v2

`out/product-demo/lidar2sim-promo-v2.mp4`: сокращение до ~27 секунд,
без синтезированной музыки, переходы dissolve по 0.4 с. Полный интервал
измеренного движения сохранён внутри физического эпизода. Геометрия не исправлялась
в монтаже: разрывы скана/реконструкции нельзя скрывать как якобы устранённые дефекты.

```sh
ffmpeg -y -filter_complex_threads 2 -i out/product-demo/lidar2sim-promo.mp4 \
  -filter_complex_script tools/promo-v2.fffilter -map '[out]' -an \
  -c:v libx264 -preset fast -crf 19 -pix_fmt yuv420p -movflags +faststart \
  out/product-demo/lidar2sim-promo-v2.mp4
```
